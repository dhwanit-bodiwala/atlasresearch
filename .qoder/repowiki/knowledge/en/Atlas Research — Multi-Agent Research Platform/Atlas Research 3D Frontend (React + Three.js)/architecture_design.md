The app is a standard Vite + React entry point (`main.jsx` → `App.jsx`) that mounts a full-screen `<Canvas>` from `@react-three/fiber`. The 3D world lives under `src/components/crystal/`: `CrystalScene.jsx` composes lighting, environment HDRIs, the `EffectComposer` post-processing chain (Bloom, ChromaticAberration, Vignette, Noise, DepthOfField, ToneMapping), and delegates geometry to `CrystalMesh.jsx` (a GLTF model split into shell/core meshes with `MeshTransmissionMaterial`) and `CrystalParticles.jsx`. Global UI state (scene phase, crystal lifecycle, pipeline stage, chat messages, data shards) is centralized in a single Zustand store (`src/store/atlasStore.js`). Cross-cutting concerns are kept minimal: WebSocket event type constants live in `src/utils/wsEventTypes.js`, Tailwind styles in `src/styles/globals.css`, and GLSL shaders are imported directly via `vite-plugin-glsl` under `src/components/crystal/shaders/`. Asset generation utilities (`scripts/generate_crystal.mjs` / `.py`) produce the `/crystal.glb` model placed in `public/`.
