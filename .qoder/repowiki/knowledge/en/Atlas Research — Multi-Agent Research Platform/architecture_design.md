The project is split into two cooperating services with a strict client-server boundary: the FastAPI backend (port 8000) owns the agent pipeline and memory store, while the React/Vite frontend (port 5173) is a pure visual consumer. Communication flows one-way via WebSocket at `ws://localhost:8000/ws/research` — the frontend never calls Ollama or PostgreSQL directly. The frontend's Zustand store mirrors the backend's event stream (`wsEventTypes.js` defines all 30+ event codes), and each event maps to a deterministic visual reaction (shaft zone lighting, shard spawning, crystal morph states). The master document `ATLASRESEARCH_MASTER.md` serves as the single source of truth for both development and AI-assisted generation, enforcing a shared design language (crystallisation metaphor, immutable CSS tokens, five custom GLSL shaders) across every component. Development follows a strict phased build order defined in section 20, with explicit stop gates between phases.
