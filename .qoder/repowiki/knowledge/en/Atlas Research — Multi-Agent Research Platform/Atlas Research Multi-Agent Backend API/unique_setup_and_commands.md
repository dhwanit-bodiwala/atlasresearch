Requires a running PostgreSQL instance with a database named `AtlasResearch`, a user `postgres` with password `9582`, and a `memories` table supporting pgvector vectors. Ollama must be running locally at `http://localhost:11434` with the qwen3 8b and 14b models pulled. Dependencies are installed from `requirements.txt` inside the provided `venv/`. The backend is started by running `python main.py` (or via uvicorn), and the CORS middleware is preconfigured to allow `http://localhost:5173` (the frontend dev server).
