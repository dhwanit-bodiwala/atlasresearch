Professional animation library used for all motion choreography including camera movements, crystal transformations, shard explosions, and UI transitions. GSAP timelines orchestrate complex sequences like the crystal shatter effect, descent animations through the shaft, and emergence transitions. The @gsap/react package provides hooks for integrating GSAP with React lifecycle.
